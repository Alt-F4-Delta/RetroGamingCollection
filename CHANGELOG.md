# Changelog

## 1.00

- Windows installer with the .NET runtime included.
- Check for updates from GitHub Releases, with release notes before installation.
- Verified installer downloads with SHA-256 integrity checks and cancellation.
- Installed settings and saves kept outside the application installation directory.
- Import existing portable library registrations and emulator paths on this PC.
- SNES and Genesis launching with a blue/purple interface, search and rescanning.
- Language and USA region filters, with USA releases without language tags shown by default.

Future release notes are generated from commit subjects since the previous release.
